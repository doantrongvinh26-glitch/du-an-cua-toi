Kịch bản / Video mẫu

Sắp ra mắt: nhập kịch bản, tải video mẫu, hoặc dán link YouTube/TikTok/Facebook Reel để phân tích thành các cảnh.

Prompt

Sắp ra mắt: sinh prompt Veo3 chi tiết cho từng cảnh từ kịch bản hoặc video mẫu.

Render Veo3

Sắp ra mắt: gửi prompt tới Veo3 và theo dõi tiến trình render từng cảnh.

Ghép cảnh

Sắp ra mắt: ghép các cảnh đã render bằng hiệu ứng chuyển cảnh mượt (crossfade), dùng chung engine với chuyen-canh.sh.

Cài đặt

Gemini API Key

Dùng để gọi Veo3 qua Gemini API chính thức. Đăng nhập bằng tài khoản Gmail bất kỳ (tài khoản chính hoặc phụ, không bắt buộc phải là tài khoản có Veo3 Ultra), tạo API Key rồi dán vào ô bên dưới.

Mở trang lấy Gemini API Key ↗

Labs Token

Dùng để truy cập Veo3 qua Google Labs (Flow) bằng token trích từ trình duyệt, thay cho API trả phí chính thức. Cài tiện ích bên dưới, đăng nhập labs.google bằng tài khoản có quyền Veo3, lấy token rồi dán vào đây.

Mở tiện ích lấy Labs Token ↗

⚠️ Đây là cách truy cập không chính thức (không qua API công khai của Google), có thể vi phạm Điều khoản dịch vụ của Google Labs và tiềm ẩn rủi ro bị khoá/hạn chế tài khoản dùng để lấy token. Chỉ nên dùng tài khoản bạn chấp nhận rủi ro này.
